# CAD Cloud — PDG Systems

Уеб платформа за проектиране на фотоволтаични системи и електрически табла.

## Демонстрация
След активиране на GitHub Pages (Settings → Pages → Deploy from a branch → main / root):
https://pgeorgiev90-eng.github.io/Cad-Cloud/

## Текущ прототип
Отворете `index.html` директно в браузър или през GitHub Pages.

- Чертайте многоъгълен покрив върху мрежа
- Поставяйте и изтривайте панели
- Изчислявайте брой панели, ориентировъчна мощност и площ
- Запазвайте проект локално в браузъра, импортирайте и експортирайте JSON
- Интерфейс на български език

## Ограничения
Това е демонстрационен MVP, **не** инструмент за готови инженерни проекти. Размерите на панелите са условни. Няма засенчване, наклон, отстояния, електрически проверки, автентикация или сървърно съхранение. Площта се определя от зададения мащаб.

## Планирано развитие
1. Точен мащаб, редактиране на контури и реални размери на панели
2. Завъртане, преместване, препятствия и автоматично разполагане
3. Електрически табла и еднолинейни схеми
4. Регистрация, облачно съхранение и роли
5. Тестване и продукционен хостинг
